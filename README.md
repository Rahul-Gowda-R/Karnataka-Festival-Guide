# 🎉 Karnataka Festival Guide

An AI-powered cultural tourism assistant built with **React**, **TypeScript**, **Vite**, and **Google Gemini AI**. The application helps users explore Karnataka's vibrant festivals through interactive conversations, personalized recommendations, travel tips, and cultural insights in both **English** and **Kannada**.

---

# ✨ Features

* 🤖 AI-powered chatbot using Google Gemini
* 🎭 Explore Karnataka's famous festivals
* 🌏 Bilingual responses (English + Kannada)
* 💬 Real-time streaming AI responses
* ⚡ Interactive quick replies and follow-up suggestions
* 📍 Festival highlights, history, and cultural significance
* 🏨 Travel, accommodation, and food recommendations
* 🗺️ Nearby attractions and sightseeing suggestions
* 📱 Responsive and modern user interface

# 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Rahul-Gowda-R/Karnataka-Festival-Guide.git
cd Karnataka-Festival-Guide
```

### Install dependencies

```bash
npm install
```

### Configure Gemini API

Create a `.env.local` file in the project root and add your API key:

```env
API_KEY=YOUR_GEMINI_API_KEY
```

Obtain a Gemini API key from Google AI Studio.

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
